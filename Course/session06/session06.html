Python Beginner Course - Session 6

Topic: Lists, Dictionaries, Tuples, and For Each Loop

1. Lists in Python

A list is a mutable, ordered collection of items. Lists can contain any data type and are defined using square brackets [].

Example 1: Creating and Accessing Lists

# Creating a list
fruits = ["apple", "banana", "orange", "grape"]
print(fruits)  # Output: ['apple', 'banana', 'orange', 'grape']

# Accessing elements (indexing)
print(fruits[0])  # Output: apple
print(fruits[-1])  # Output: grape (last item)

Example 2: Slicing Lists

# Slicing to get a portion of the list
numbers = [1, 2, 3, 4, 5]
print(numbers[1:4])  # Output: [2, 3, 4]
print(numbers[:3])   # Output: [1, 2, 3]
print(numbers[2:])   # Output: [3, 4, 5]
print(numbers[::2])  # Output: [1, 3, 5] (every second item)

Example 3: Modifying Lists

# Modifying list elements
colors = ["red", "blue", "green"]
colors[1] = "yellow"
print(colors)  # Output: ['red', 'yellow', 'green']

# Adding elements
colors.append("purple")
print(colors)  # Output: ['red', 'yellow', 'green', 'purple']

# Removing elements
colors.pop()
print(colors)  # Output: ['red', 'yellow', 'green']

Note: Lists are mutable, meaning you can change their contents after creation. Indexing starts at 0, and negative indices count from the end.

2. Dictionaries in Python

A dictionary is an unordered collection of key-value pairs, defined using curly braces {}. Keys must be unique and immutable.

Example 1: Creating and Accessing Dictionaries

# Creating a dictionary
student = {"name": "Alice", "age": 20, "major": "Computer Science"}
print(student)  # Output: {'name': 'Alice', 'age': 20, 'major': 'Computer Science'}

# Accessing values
print(student["name"])  # Output: Alice
print(student.get("age"))  # Output: 20

Example 2: Modifying Dictionaries

# Modifying a value
student["age"] = 21
print(student)  # Output: {'name': 'Alice', 'age': 21, 'major': 'Computer Science'}

# Adding a new key-value pair
student["gpa"] = 3.8
print(student)  # Output: {'name': 'Alice', 'age': 21, 'major': 'Computer Science', 'gpa': 3.8}

# Removing a key-value pair
del student["major"]
print(student)  # Output: {'name': 'Alice', 'age': 21, 'gpa': 3.8}

Note: Use .get() to safely access dictionary values to avoid errors if the key doesn't exist.

3. Tuples in Python

A tuple is an immutable, ordered collection of items, defined using parentheses ().

Example 1: Creating and Accessing Tuples

# Creating a tuple
coordinates = (10, 20)
print(coordinates)  # Output: (10, 20)

# Accessing elements
print(coordinates[0])  # Output: 10
print(coordinates[1])  # Output: 20

Example 2: Tuple Immutability

# Trying to modify a tuple (will raise an error)
coordinates = (10, 20)
# coordinates[0] = 15  # This will cause an error because tuples are immutable
print(coordinates)  # Output: (10, 20)

Note: Tuples are immutable, so they cannot be changed after creation. Use them when you want data to remain constant.

4. For Each Loop in Python

The for loop in Python iterates over items in a sequence (like a list, tuple, or dictionary).

Example 1: Looping Through a List

# Iterating over a list
animals = ["cat", "dog", "bird"]
for animal in animals:
    print(f"I have a {animal}")
# Output:
# I have a cat
# I have a dog
# I have a bird

Example 2: Looping Through a Dictionary

# Iterating over dictionary keys
person = {"name": "Bob", "age": 25, "city": "New York"}
for key in person:
    print(f"{key}: {person[key]}")
# Output:
# name: Bob
# age: 25
# city: New York

Example 3: Looping Through a Tuple

# Iterating over a tuple
days = ("Monday", "Tuesday", "Wednesday")
for day in days:
    print(f"Today is {day}")
# Output:
# Today is Monday
# Today is Tuesday
# Today is Wednesday

Note: The for each loop in Python is written as for item in sequence. It automatically iterates over each item in the sequence.
