Topic: Functions in Python

1. Introduction to Functions

Functions are reusable blocks of code that perform a specific task. They are defined using the def keyword and can take inputs (parameters) and return outputs.

Example 1: Defining and Calling a Simple Function

# Defining a function
def greet():
    print("Hello, welcome to Python!")

# Calling the function
greet()  # Output: Hello, welcome to Python!

Example 2: Function with Parameters

# Function with a parameter
def greet_person(name):
    print(f"Hello, {name}!")

# Calling the function with different arguments
greet_person("Alice")  # Output: Hello, Alice!
greet_person("Bob")   # Output: Hello, Bob!

Note: Parameters are placeholders in the function definition, and arguments are the actual values passed when calling the function.

2. Functions with Return Values

Functions can return values using the return statement, allowing the result to be used elsewhere in the code.

Example 1: Returning a Value

# Function that returns a value
def square(number):
    return number * number

# Using the returned value
result = square(5)
print(result)  # Output: 25

Example 2: Function with Multiple Parameters

# Function with multiple parameters
def add_numbers(a, b):
    return a + b

# Using the function
sum = add_numbers(3, 7)
print(sum)  # Output: 10

Note: The return statement exits the function and sends a value back to the caller. If no return is specified, the function returns None.

3. Default Parameters and Keyword Arguments

Functions can have default parameter values and can be called using keyword arguments for clarity.

Example 1: Default Parameters

# Function with a default parameter
def introduce(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

# Calling with and without the default parameter
introduce("Alice")          # Output: Hello, Alice!
introduce("Bob", "Hi")      # Output: Hi, Bob!

Example 2: Keyword Arguments

# Function with multiple parameters
def describe_person(name, age):
    print(f"{name} is {age} years old.")

# Using keyword arguments
describe_person(age=25, name="Charlie")  # Output: Charlie is 25 years old.

Note: Default parameters allow flexibility, and keyword arguments improve code readability by explicitly naming the arguments.

4. Functions with Lists and Dictionaries

Functions can work with data structures like lists and dictionaries to perform useful tasks.

Example 1: Processing a List

# Function to print list items
def print_list(items):
    for item in items:
        print(item)

# Calling the function
fruits = ["apple", "banana", "orange"]
print_list(fruits)
# Output:
# apple
# banana
# orange

Example 2: Updating a Dictionary

# Function to add a key-value pair to a dictionary
def add_to_dict(dictionary, key, value):
    dictionary[key] = value
    return dictionary

# Using the function
student = {"name": "Alice", "age": 20}
updated_student = add_to_dict(student, "grade", "A")
print(updated_student)  # Output: {'name': 'Alice', 'age': 20, 'grade': 'A'}
