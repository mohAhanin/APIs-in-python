2. Why Files?

📘 Files allow data persistence, meaning data remains even after a program ends. We can read and write .txt files using Python.

Discussion: What happens to variables when a program ends? Can you imagine a program saving your notes, scores, or preferences?

3. Writing to Files

Basic Syntax

🧪 Example 1: Writing to a File (Overwrite Mode)

file = open("myfile.txt", "w")  # "w" means write (overwrites file)
file.write("Hello world!\n")
file.write("This is line 2.\n")
file.close()

Creates or overwrites myfile.txt with two lines.

Example 2: Appending to a File

file = open("log.txt", "a")  # "a" means append (adds to file)
file.write("New log entry...\n")
file.close()

Adds a new line to log.txt without overwriting existing content.

Example 3: Writing a List to a File

fruits = ["apple", "banana", "orange"]
file = open("fruits.txt", "w")
for fruit in fruits:
    file.write(f"{fruit}\n")
file.close()

Writes each fruit on a new line in fruits.txt.

File Modes:

ModeMeaning
"w"Write (overwrites file)
"a"Append (adds to file)
"r"Read only

4. Reading from Files

Example 1: Reading Entire File

file = open("myfile.txt", "r")
content = file.read()
print(content)
file.close()

Reads all content as a single string.

Example 2: Reading Line by Line

file = open("myfile.txt", "r")
print(file.readline())  # Reads one line
file.close()

Reads the first line of the file.

Example 3: Reading All Lines as a List

file = open("myfile.txt", "r")
lines = file.readlines()
print(lines)  # Prints list of lines
file.close()

Reads all lines into a list.

Example 4: Looping Through Lines

file = open("myfile.txt", "r")
for line in file:
    print(line.strip())  # strip() removes trailing newlines
file.close()

Reads and prints each line without extra newlines.

Tip: .read() returns a big string, .readlines() returns a list of lines, and .readline() reads one line at a time.

5. Guided Activity: Message Logger

🛠️ Create a program that:

  1. Asks the user for their name and message
  2. Appends the input to messages.txt in the format: [Name]: Message
  3. Prints: "Your message has been saved!"

Solution

name = input("Enter your name: ")
message = input("Enter your message: ")
file = open("messages.txt", "a")
file.write(f"[{name}]: {message}\n")
file.close()
print("Your message has been saved!")

Example Output in File:

[Ali]: Hello everyone!
[Sara]: Python is cool.

Extension: Read and Display Messages

file = open("messages.txt", "r")
print("All messages:")
for line in file:
    print(line.strip())
file.close()

Reads and prints all messages from messages.txt.

Homework: Build a Simple Journal Program

🏠 Write a program that:

  • Asks the user for a title and entry
  • Saves it in a file named journal.txt
  • Appends every entry in the format:
=== Title ===
Entry text here
----------------------------

Homework Solution

title = input("Enter your journal title: ")
entry = input("Enter your journal entry: ")
file = open("journal.txt", "a")
file.write(f"=== {title} ===\n")
file.write(f"{entry}\n")
file.write("----------------------------\n")
file.close()
print("Journal entry saved!")

Additional Homework Example: Read Journal Entries

file = open("journal.txt", "r")
print("Your journal entries:")
print(file.read())
file.close()

Reads and displays all journal entries.

Key Takeaways:

✅ File handling allows data persistence.

✅ Use "w" to overwrite, "a" to append, and "r" to read.

✅ Always close files with close() to save changes.
