⚖️ عملگرهای مقایسه‌ای

گاهی می‌خوایم بدونیم دو مقدار با هم برابرن یا نه، یا کدوم بزرگ‌تره. برای این کار از عملگرهای مقایسه‌ای استفاده می‌کنیم.

عملگرتوضیحاتمثال
==برابر است با3 == 3
!=برابر نیست با2 != 3
>بزرگ‌تر است از9 > 4
<کوچک‌تر است از5 < 11
>=بزرگ‌تر یا مساوی است با14 >= 13
<=کوچک‌تر یا مساوی است با2 <= 3

نتیجه‌ی عملیات‌های مقایسه‌ای همیشه یکی از این دو مقدار خاص هست: True (درست) یا False (نادرست).

مثالprint(3 == 3) # True print(2 != 3) # True print(9 > 4) # True print(5 < 11) # True print(14 >= 13) # True print(2 <= 3) # True
خروجیTrue True True True True True
⚠️ مراقب باش! علامت == برای «مقایسه» است، ولی علامت = برای «تخصیص مقدار» است. این دو کاملاً فرق دارن و اشتباه گرفتنشون یکی از رایج‌ترین اشتباهات مبتدی‌هاست!

🔲 متغیرهای بولی (Boolean)

به مقدارهایی مثل True و False که از مقایسه به دست میان، مقدار بولی (Boolean) می‌گیم. می‌تونیم این مقدارها رو هم داخل متغیر ذخیره کنیم.

کدa = 13 == 13 b = 12 == 12 print(b, a) c = a & b c
خروجیTrue True True

این کد چیکار کرد؟

  • a = 13 == 13 یعنی حاصل مقایسه (که True هست) رو داخل متغیر a ذخیره کردیم.
  • به همین شکل b هم مقدار True رو گرفت.
  • c = a & b یعنی a و b رو با علامت & با هم ترکیب کردیم؛ چون هر دو True بودن، نتیجه هم True شد.
💡 نکته: علامت & در پایتون یک عملگر «بیتی» است که روی مقدارهای بولی هم مثل «و منطقی» عمل می‌کنه، ولی روش استاندارد و خواناتر برای کار با مقدارهای بولی استفاده از کلمه‌ی and است که الان می‌بینیمش.

🧠 عملگرهای منطقی

وقتی چند شرط داریم و می‌خوایم اون‌ها رو با هم ترکیب کنیم، از عملگرهای منطقی استفاده می‌کنیم.

عملگرمثالتوضیحات
anda and bاگر هر دو متغیر True باشند، نتیجه True می‌شود.
ora or bاگر حداقل یکی از دو متغیر True باشد، نتیجه True می‌شود.
notnot aاگر متغیر False باشد نتیجه True می‌شود و برعکس.
مثال با anda = 13 == 13 # True b = 12 == 12 # True print(a and b) # True, چون هر دو True هستند
خروجیTrue
مثال با orx = 5 > 10 # False y = 5 < 10 # True print(x or y) # True, چون حداقل یکی True است
خروجیTrue
مثال با notis_raining = False print(not is_raining) # True
خروجیTrue

📓 تکلیف جلسه سوم

این تمرین‌ها رو توی یک فایل پایتون بنویس و اجرا کن. فعلاً فقط از عملگرهای مقایسه‌ای و منطقی استفاده کن و نتیجه رو مستقیم چاپ کن — نیازی به if نیست. 💪

۱. مقایسه‌ی دو عدد

دو عدد از کاربر بگیر و نتیجه‌ی این مقایسه‌ها رو چاپ کن: آیا برابرند؟ آیا نابرابرند؟ کدوم بزرگ‌تره؟ کدوم کوچک‌تر یا مساویه؟

۲. سن رانندگی

سن یک نفر رو از کاربر بگیر و با عملگر >= بررسی کن که آیا سنش ۱۸ یا بیشتره. نتیجه (True یا False) رو چاپ کن.

۳. ترکیب با and

دو نمره‌ی درسی از کاربر بگیر. با عملگر and بررسی کن که آیا هر دو نمره بالای ۱۰ هستند یا نه، و نتیجه رو چاپ کن.

۴. ترکیب با or

دو عدد از کاربر بگیر. با عملگر or بررسی کن که آیا حداقل یکی از اون دو عدد بزرگ‌تر از ۱۰۰ هست یا نه.

۵. معکوس کردن با not

یک متغیر بولی به اسم is_sunny بساز و مقدار True یا False بهش بده. با not مقدار معکوسش رو چاپ کن.

۶. سوال اصلی

سه عدد از کاربر بگیر و با ترکیب and و or بررسی کن که آیا «عدد اول از عدد دوم بزرگ‌تره و عدد سوم هم مثبته». نتیجه رو چاپ کن.
