تا پایان این جلسه باید بتوانی:

  1. توضیح بدهی برنامه‌نویسی چیست.

  4. از کاربر ورودی دریافت کنی.

۱. برنامه‌نویسی چیست؟

برنامه‌نویسی یعنی نوشتن دستورهایی که کامپیوتر بتواند آن‌ها را اجرا کند. کامپیوتر خودش نمی‌داند ما چه می‌خواهیم؛ باید مراحل کار را دقیق و به ترتیب به آن بگوییم.

تشبیه ساده: برنامه‌نویسی شبیه نوشتن دستور پخت غذاست. دستور پخت باید مرحله‌به‌مرحله و دقیق باشد؛ برنامه هم همین‌طور.

۲. Python در دنیای واقعی

Python فقط یک زبان برای تمرین‌های کلاس نیست. از آن در حوزه‌های مختلف استفاده می‌شود:

  • 🕹️ بازی‌ها: توسعه بازی و ابزارهایی مثل Pygame.
  • 🤖 هوش مصنوعی و رباتیک: یادگیری ماشین و ساخت سیستم‌های هوشمند.
  • 🌐 توسعه وب: ساخت بخش Back-end وب‌سایت‌ها با ابزارهایی مانند Django و Flask.
  • 📊 علم داده: تحلیل داده‌ها و ساخت نمودارها.
  • 💸 مالی: تحلیل ریسک و الگوریتم‌های مالی.
سؤال کلاسی: کدام حوزه برایت جذاب‌تر است؟ اگر با Python می‌توانستی هر چیزی بسازی، چه چیزی می‌ساختی؟

۳. این دوره چه چیزهایی دارد؟

هدف دوره این است که کم‌کم از نوشتن دستورهای ساده به سمت حل مسئله و ساخت پروژه برویم:

  1. هفته اول: Python و Hello World
  2. هفته دوم: متغیرها و Stringها
  3. هفته سوم: شرط‌ها و تصمیم‌گیری
  4. هفته چهارم: حلقه‌ها و تکرار
  5. هفته پنجم: Listها و مجموعه‌های داده
  6. هفته ششم: Functionها
  7. هفته هفتم و هشتم: پروژه‌ها 🚀
یادآوری: برای برنامه‌نویس شدن لازم نیست نابغه ریاضی یا متخصص کامپیوتر باشی. کنجکاوی، تمرین و اشتباه کردن بخشی از مسیر یادگیری است.

۵. اولین برنامه: Hello, World!

در بسیاری از دوره‌های برنامه‌نویسی، یکی از اولین برنامه‌ها نمایش دادن عبارت «سلام دنیا» است.

کد
print("Hello, world!")
خروجی
Hello, world!

این کد چه کاری انجام می‌دهد؟

  • print() یک تابع داخلی Python برای نمایش اطلاعات است.
  • "Hello, world!" یک String یا داده متنی است.
  • علامت‌های نقل‌قول نشان می‌دهند که چیزی که نوشته‌ایم متن است.
تمرین ۱ — Say Hello 👋

سه دستور print() بنویس و خودت را معرفی کن. می‌توانی از Emoji هم استفاده کنی.

print("Hello, my name is Chad!")
Hello, my name is Chad!
print("Hi there!")
print("I'm learning Python.")
print("🚀 Let's go!")
Hi there!
I'm learning Python.
🚀 Let's go!
حالا نوبت توست!

سه print() بنویس که نام، علاقه و یک جمله درباره یادگیری Python را نمایش دهد.

print("👋 Hi, I'm Leo.")
print("🎮 I love video games.")
print("🐍 I'm learning Python!")
👋 Hi, I'm Leo.
🎮 I love video games.
🐍 I'm learning Python!

۶. متغیر چیست؟

متغیر را می‌توان مثل یک ظرف دارای برچسب تصور کرد. داخل این ظرف یک مقدار قرار می‌دهیم و با استفاده از نام آن، بعداً به مقدار دسترسی پیدا می‌کنیم.

name = "Alex"

در اینجا name نام متغیر و "Alex" مقدار آن است.

name = "Alice"
age = 12
height = 4.5
مقدارنوع دادهتوضیح
"Alice"str / stringمتن

۷. یک نکته مهم: نوع داده‌ها

Python بین متن و عدد تفاوت می‌گذارد. 12 یک عدد است، اما "12" یک متن است.

Name = "John"     # Python is case-sensitive
age = "12" + 1    # Can't mix string and number
TypeError: can only concatenate str (not "int") to str

همچنین Python به حروف بزرگ و کوچک حساس است؛ بنابراین name و Name دو نام متفاوت هستند.

قانون خوب: نام متغیر را واضح و معنی‌دار انتخاب کن. مثلاً student_name از x قابل فهم‌تر است.

۸. یک تمرین با متغیرها

تمرین ۲

برنامه‌ای بنویس که این اطلاعات را ذخیره و نمایش دهد:

  • Name — رشته

  • Height — عدد اعشاری

۹. f-string؛ راه ساده‌تر برای ساخت متن

با f-string می‌توانیم مقدار متغیرها را به‌سادگی داخل یک جمله قرار دهیم. کافی است قبل از رشته حرف f بگذاریم و متغیر را داخل { } بنویسیم.

print(f"My name is {my_name} and I love {my_hobby}.")
My name is ali and I love drawing.
تمرین ۳ — سن سال آینده

سن خودت را در یک متغیر ذخیره کن و برنامه‌ای بنویس که سن تو در سال آینده را حساب کند.

age = 13
next_year = age + 1
print("Next year, I’ll be", next_year)
Next year, I’ll be 14

۱۰. دریافت اطلاعات از کاربر با input

تا اینجا اطلاعات را خودمان داخل برنامه نوشته‌ایم. برنامه‌های تعاملی باید بتوانند از کاربر سؤال بپرسند و پاسخ او را دریافت کنند.

تابع input() برای دریافت ورودی از کاربر استفاده می‌شود.

name = input("What is your name? ")
print("Hello, " + name + "!")
What is your name? ali
Hello, ali!
color = input("What is your favorite color? ")
print("Wow, I like " + color + " too!")
What is your favorite color? red
Wow, I like red too!
نکته بسیار مهم: خروجی input() به صورت string دریافت می‌شود؛ حتی اگر کاربر یک عدد تایپ کند.

۱۱. چرا این برنامه خطا می‌دهد؟

age = input("How old are you? ")
print(age + 1)  # 🚫 Error!
How old are you? 12
TypeError: can only concatenate str (not "int") to str

کاربر 12 را وارد کرده، اما Python آن را به صورت متن یعنی "12" دریافت کرده است. بنابراین نمی‌توانیم آن را مستقیماً با عدد 1 جمع کنیم.

راه‌حل: متن را به عدد صحیح تبدیل کنیم.

age = int(input("How old are you? "))
print("Next year, you'll be", age + 1)
How old are you? 15
Next year, you'll be 16

اینجا int() مقدار واردشده را به یک عدد صحیح تبدیل می‌کند.

۱۲. تمرین: برنامه پرسش‌نامه

برنامه‌ای بنویس که ۲ یا ۳ سؤال از کاربر بپرسد و بعد پاسخ‌های او را در یک جمله ترکیب کند.

۱۳. تمرین: داستان‌ساز 🎭

از کاربر چند کلمه بگیر و با استفاده از آن‌ها یک جمله یا داستان کوتاه بساز.

animal = input("Enter an animal: ")
adjective = input("Enter an adjective: ")
verb = input("Enter a verb: ")

print("Today I saw a " + adjective + " " + animal + " " + verb + " in the park.")
Enter an animal: re
Enter an adjective: s
Enter a verb: fd
Today I saw a s re fd in the park.

همین خروجی را می‌توان با f-string خواناتر نوشت:

print(f"Today I saw a {adjective} {animal} {verb} in the park.")
Today I saw a s re fd in the park.
